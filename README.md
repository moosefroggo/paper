## About the site

The site uses a compact 2×2 layout. It is built with HTML and CSS, with no application framework or build step. It includes video case studies, motion, responsive layouts, and an interactive 3D detail.

### Run locally

Start a local server so the media and 3D assets load:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).
